S&OE Inteligência Comercial — Streamlit dashboard for commercial supply-chain intelligence at Aço Cearense. Tracks weekly sales pace vs. plan, propensity scoring, Monte Carlo demand sensing, and assertiveness metrics across three companies (ACC, ACI, SIN).

## Summary

- `app/` — Streamlit application (entry point + all modules)
- `data/` — raw CSV/XLSX inputs and processed parquet outputs
- `scripts/` — data pipeline, ETL, and sync utilities
- `src/` — placeholder pipeline scripts (currently empty stubs)
- `tests/` — pytest suite for engines and integration
- `Dockerfile` — builds container for HF Spaces (port 7860, runs start.sh)
- `start.sh` — container entrypoint: `streamlit run app/dashboard.py`
- `requirements.txt` — Python dependencies
- `ATUALIZAR_E_RODAR.bat` — daily workflow: increment sales → ETL → run dashboard
- `FAZER_PUSH.bat` — deploys to HF Spaces after validation
- `SUBIR_DADOS_GDRIVE.bat` — uploads processed parquets to Google Drive
- `SÓ_RODAR_DASHBOARD.bat` — runs dashboard without ETL step
- `AGENTS.md` — AI agent configuration for Claude Code sessions
- `.agents/` — framework internals: skills and agent prompt files (do not recurse)
- `.memory/` — framework internals: session memory files (do not recurse)

## Constraints

- MUST NOT commit `credentials_gdrive.json`, `token_gdrive.json`, or `.streamlit/secrets.toml`
- MUST run `scripts/atualiza_dados.py` before running the dashboard to refresh parquets
- MUST run `app/dashboard.py` as the Streamlit entry point (not any module directly)
