The Streamlit application root. `dashboard.py` is the sole entry point; it loads data, renders the sidebar/filters, and delegates each tab to a module in `modules/`. Shared utilities and business engines live in `utils/` and `engines/`.

## Summary

- `dashboard.py` — entry point: page config, CSS injection, data loading/caching, chart helpers (sparkline, gauge, daily bars), tab routing, sidebar filters
- `config.py` — business constants: excluded product lines, name mappings, gerência config, UF→region map, propensity score parameters
- `modules/` — one file per dashboard tab
- `utils/` — shared helpers (data loading, auth, visual tokens, TW calendar)
- `engines/` — pure-Python scoring engines (no Streamlit dependency)
- `assets/produtos/` — PNG images for each product line (VERGALHAO, BOBINA, etc.), used in UI cards

## Constraints

- MUST call `st.set_page_config` before any other Streamlit command — it is the first statement in `dashboard.py`
- MUST NOT import Streamlit in `engines/`; engines are pure-Python and tested independently

## Guidance

- Tab modules receive pre-filtered DataFrames from `dashboard.py`; they SHOULD NOT reload data themselves
