One module per dashboard tab. Each file exposes a `render()` function called by `dashboard.py` after data is loaded and filtered. Modules import from `engines/` and `utils/` but never from each other.

## Summary

- `ritmo_semanal.py` — Tab 1 "Visão Geral": daily bar chart, weekly gauge, pace cards, close-the-gap line
- `plano_comercial.py` — Tab 2 "Plano Comercial": 10-week demand horizon, exception alerts, what-if simulator, opportunity matrix (propensity × volume scatter), client table
- `demand_sensing.py` — Tab 3 "Demand Sensing": MAPE/Bias/Hit Rate on completed weeks, Monte Carlo (1 000 simulations, P10–P90) forecast 8 weeks ahead, S&OP/S&OE overlay
- `dashboard_uf.py` — Tab 4 "Dashboard UF": Brazil bubble map (offline, embedded coordinates), risk/opportunity cards by state, UF detail table
- `assertividade_plano.py` — Tab 5 "Assertividade do Plano": Real vs S&OP vs S&OE chart (12 hist + 8 future weeks), aggregated weekly metrics table, per-line detail expanders
- `matriz_semanal.py` — Heat-map component (Semana × Linha) used inside Tab 2
- `score_propensao.py` — "Prioridade de Contato" sub-section inside Tab 2: ranked client table with propensity tiers

## Constraints

- MUST expose a `render()` function as the public interface
- MUST NOT reload parquet data; receive filtered DataFrames from `dashboard.py`
