Data directory. `raw/` holds source files provided by the business; `processed/` holds parquets generated by the ETL and consumed by the dashboard. Contains client data — do not read or commit file contents.

## Summary

- `raw/` — source inputs: `base_vendas_soe.csv` (unified sales Jan/2024+), `base_previsao.xlsx` (S&OE + S&OP forecast by Technical Week)
- `processed/` — ETL outputs: `vendas_filtrada.parquet`, `vendas_unificada.parquet`, `meta_semanal.parquet`, `relatorio_qualidade.txt`

## Constraints

- MUST NOT commit files in `raw/` or `processed/` to version control (client data)
- `processed/` files are regenerated by `scripts/atualiza_dados.py` — do not hand-edit them
